待錄入（第 1 階段第 9–10 週）/ To enter in Phase 1, weeks 9–10:

- 中電 CLP：2005 年至今每年的排放系數，來源 `src-clp-sr`，region `HK-CLP`
- 港燈 HK Electric：2005 年至今每年的排放系數，來源 `src-hke-sr`，region `HK-HKE`

每年一個檔案，例如 `clp-2024.yaml`，id `hk.energy.electricity.clp.2024`。
數值必須照抄報告原文並填寫頁碼；不要從二手資料轉抄。
One file per year. Copy the value exactly from the report and record the page.
